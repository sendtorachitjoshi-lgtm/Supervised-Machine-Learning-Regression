Supervised Machine Learning: Regression

This repository contains my learning notes, Python implementations, and practice exercises from the IBM Machine Learning with Python course on Coursera, focusing on supervised machine learning and regression algorithms.

The objective is to understand the mathematical foundations of regression, evaluate model performance, and implement machine learning techniques using Python.

Topics Covered

1. Introduction to Regression

Supervised learning fundamentals

Regression vs. classification

Simple and multiple linear regression

Understanding features, target variables, and predictions

2. Model Training and Optimization

Linear regression model fitting

Cost and loss functions

Mean Squared Error (MSE)

Mean Absolute Error (MAE)

Gradient descent

Learning rate and parameter optimization

Actual values vs. predicted values

Residuals and prediction errors

3. Model Evaluation

Evaluating regression performance using MSE and MAE

Understanding prediction errors

Comparing model predictions with actual values

Understanding the impact of model parameters on performance

4. Python Implementation

Python and NumPy for mathematical computations

Pandas for data manipulation

Matplotlib for data visualization

Scikit-learn for implementing regression models
